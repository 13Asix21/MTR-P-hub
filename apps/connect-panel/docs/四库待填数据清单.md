## 0. 现在的用法（2026-11-23 简化后）

- 右上角 **⚙ 图标**随时打开设置；扫描后工具栏也有「⚙ 库设置」。

也就是说：**打开设置 → 点测试连接 → 通过 → 关闭**，就能用。

| 代理 sharecode | 代理分享链接里的访问码 | 固定的 `QOPTB45RQL`（取自代理链接 `?sharecode=QOPTB45RQL`） |

### 参考值（当前实测可用）

| 字段 | 参考值 |
| --- | --- |
| `space_id` | `c3f157b3d03d4c7fa46a8fb8e70b1ae7` |

> 建议先用 `MTR-P-验证` 测试，确认链路通了再改成正式路径。代理会按路径**逐级自动建文件夹**。

### 三个常见错法

1. **把审核页的 sharecode 填进来**（`R6JHCUP2WX`）→ 会 403「链接不完整」。必须用代理自己的 `QOPTB45RQL`。
2. **代理地址写成网关反代路径**（如 `.../mtrp/lexiang`）→ 前端会自动补 `/mtrp/transfer`，自定义路径会导致 404 或 501。
3. **填了 token** → 保存时直接报错，这是设计如此，不是 bug。

## 2. T 库（Obsidian 试运行区）与 R 库（冷区）

### 字段

| 字段 | 空着会怎样 | 建议 |
| --- | --- | --- |
| 库内起始目录 | 扫描**整个库** | 想只看某几个目录时填，例如 `2-Permanent` |
| 附加目录 | 不额外加目录 | 需要同时扫多个不连续目录时填，如 `Inbox, 3-Knowledge-Graph` |
| 关注标签 | 不记录 | 只作台账参考，不参与过滤 |

### 参考值

| 场景 | vault_root | managed_roots | tags |
| --- | --- | --- | --- |
| 整库审核（推荐先这样） | 空 | 空 | `mtr/trial`（T）/ `mtr/rarely`（R） |
| 只看 PARA 区 | `2-Permanent` | 空 | 同上 |
| PARA + 收件箱 | `2-Permanent` | `0-Inbox` | 同上 |

### 重要说明

- 目录是**库内相对路径**，不能填 `C:/Users/...` 这种绝对路径，也不能含 `..`。
- Obsidian 的**目录读取授权仍然只能在每台机器上单独授予**，云端只同步目录设置，不同步授权。
- 已确认：T 库的目录设置现在会**真正参与扫描**（`ui.js` 的 `authorizeAndScan` 会读取云端配置）；之前只保存不生效的问题已修。
- R 库与 T 库共用同一次扫描结果，只是标签口径不同。

## 4. 填写步骤

1. 打开审核工作台，点「在线设置 · 我的库连接」。
2. 未登录先登录：**手机号 + 短信验证码**，或**微信扫码**。
3. 逐库填写上表，点各卡片的「保存到云端」。
4. P 库可额外点「测试连接」验证仓库可达。
5. 保存成功的标志：卡片徽章从「未配置」变为「已配置」，状态行显示你填的路径。
6. 返回首页 →「选择 Obsidian 库文件夹」授权 → 扫描。
7. 通过一篇 → 出现「传送到 M 库」→ 点击，看到「已传送到 M 库：…（条目 xxx）」即成功。

## 6. 排查对照表

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 保存时提示「连接配置不能包含凭据字段」 | 误填了 token/secret 类字段 | 删掉该字段，凭据只放代理 `.env` |
| 按钮灰着，提示需填空间、代理、sharecode | 三项缺一 | 补齐三项再保存 |
| 传送返回 403 | sharecode 用了审核页的，或代理码已变 | 改填 `QOPTB45RQL` |
| 传送返回 403 且提示「链接不完整」 | 同上，网关拒绝 | 同上 |
| 传送返回 501 / 404 | 代理地址填成了静态站点或自定义路径 | 改用 `https://mtrp-lexiang-proxy.app.workbuddy.host` |
| 扫描篇数比预期多 | `vault_root` 留空 = 整库 | 填具体目录 |
| 扫描篇数为 0 | 目录名写错（大小写/中文全角） | 用库内真实目录名 |
| 保存成功但刷新后没了 | 未登录或登录已过期 | 重新登录后保存 |

## 7. 云端表结构参考

配置保存在云数据库 `library_connections`，按账号隔离（RLS：`owner_id = auth.uid()`）。

| 列 | 类型 | 说明 |
| --- | --- | --- |
| `id` | BIGINT | 自增主键 |
| `owner_id` | TEXT | 由数据库 `DEFAULT auth.uid()` 填充，前端不发送 |
| `owner_name` | TEXT | 昵称快照，可为空 |
| `library` | TEXT | 仅 `m` / `t` / `r` / `p` |
| `label` | TEXT | 显示名称，可空 |
| `config` | JSONB | 上表字段的 JSON |
| `enabled` | BOOLEAN | 是否启用 |
| `created_at` / `updated_at` | TIMESTAMPTZ | 时间戳 |

每个账号每个库只有一行（唯一约束 `owner_id + library`），重复保存是覆盖更新。
